# Pro Hub X Classroom 11.0 + ABET

This unified repository combines Pro Hub X Classroom 10.3 administrative fixes with the OSUIT ETDE ABET Unified Hub V3.

Faculty and leadership accounts receive an **ABET Hub** navigation item. The ABET module opens inside Pro Hub and can also be opened full-screen. ABET personnel management includes safe deletion: personnel with active assigned responsibilities must first be transferred using Reassign and Remove.

The Pro Hub People & Roles section retains staged account deletion, UID blocking, instructor approval, System Health, Setup Wizard, Version Manager, GitHub-cached weather, Travel Mode, and sports tools.
