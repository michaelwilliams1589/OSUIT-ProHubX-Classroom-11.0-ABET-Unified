# Unified Pro Hub + ABET Deployment

1. Create or update a GitHub Desktop repository using all files in this package.
2. Commit and push the repository.
3. Enable GitHub Pages from `main` and `/(root)`.
4. Publish the included `firebase-rules.json` in Firebase Realtime Database.
5. Run **Update Weather Data** once in GitHub Actions.
6. Open Pro Hub, confirm the visible version badge says `v11.0`, and run System Health.
7. Sign in with an instructor/admin account and open **ABET Hub**.

ABET records currently use browser local storage. Use ABET's Backup/Restore tools regularly when moving between computers or browsers.
