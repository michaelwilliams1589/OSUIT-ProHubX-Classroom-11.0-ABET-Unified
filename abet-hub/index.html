Quick Grade Entry Instructions

The easiest way to use this file is to enter grades from the Grade Entry tab. You do not have to build a separate student list first.

What's New in This Version

  • Anonymous IDs are now scoped per course. A001 in ETDE 1283 and A001 in ETDE 1343 are treated as two different students, so you can reuse simple IDs across every class without them merging together.
  • Assessment Cycles. On the Reports tab, use Archive Current Cycle & Start New Cycle at the end of a term. It snapshots all students, grades, and evidence under a label you choose, then clears them so you can start the next term clean. Courses, SLOs, and assignments stay in place.
  • Achievement Rate by Cycle (Trend). Also on the Reports tab, this table shows each SLO's achievement rate across every archived cycle plus the current one — useful for the Continuous Improvement section of your ABET self-study.
  • Report Sign-Off. Set a status (Draft / Reviewed / Finalized), reviewer name, and review date on the Reports tab before a cycle goes into the accreditation binder.
  • Measure Category (Direct / Indirect). Assignments and Evidence items can now be tagged as Direct (exams, rubrics, labs) or Indirect (surveys, exit interviews, employer evaluations) measures.
  • Grade CSV import now previews before committing. Import Grades CSV shows a match/problem table first — nothing is written until you review it and select Confirm Import. Expected columns: Anonymous ID, Course Code, SLO Code, Assignment Name, Earned, Possible, Notes.
  • Program SLOs are now on the Dashboard. The first page anyone opens shows the full SLO list with descriptions and ABET outcome mapping, so it's clear what every assessment maps to.
  • Annual Review Log. A new tab where you add one entry every summer (or whenever the program formally reviews results) — date, reviewer, findings, actions, and follow-up. It's append-only and is never cleared by Archive Cycle, so this same file builds a running multi-year record.
  • More charts. Achievement Rate by Course, Grades Entered by Class, Direct vs. Indirect Measures, and a per-SLO visual trend across cycles, in addition to the original SLO Achievement Overview chart.
  • Printable ABET report graphs. The Reports tab now includes Outcome Attainment by SLO, Attainment by Course, Benchmark Results, and Assessment Participation. Every valid entered grade updates these graphs automatically, and they are included when using Print / Save PDF.
  • Safer detailed grade editing. The student selector now shows only anonymous IDs assigned to the selected assignment's course, reducing accidental cross-course linking.
  • Duplicate warning. Quick Grade Entry warns before adding a second record for the same anonymous student and assessment.

Guided Instructions on Every Tab

Every main tab now begins with a What to Do on This Tab panel. The panel explains the required steps, when the tab should be used, and what the completed result should look like. These instruction panels remain visible while working but are automatically hidden from the printed ABET report.

Production Edition

The Production Hub mirrors the department's existing ABET evidence organization. It provides a department readiness score, a separate workspace for every Student Outcome, the official three-year assessment schedule, a production checklist, evidence categories, quick links to Canvas uploads and reports, and automatic identification of missing assessment, evidence, review, action, or closing-the-loop requirements.

Annual Assessment Calendar and Continuations

The Annual Review tab now contains the Assess-Evaluate-Change calendar reflected in the completed ETAC Self-Study. It also includes Continuous Improvement Continuations for carrying findings and actions into later terms. Data Section Matching the Existing Outcome Workbooks

The printable report's data section now follows the organization used in the existing Student Outcome spreadsheets: an outcome-level table showing each mapped course, quantity of students, successful students, students below the threshold, skipped or missing records, assessment-tool descriptions, and success criteria. It is followed by a course-assessment block showing the course, assessment name, points possible, term, instructor, section, anonymous student grades, total students, and successful-student counts.

Complete Printable ABET Report

The Reports tab now creates a complete copy-and-paste assessment report organized around the structure used in the OSUIT ETAC Self-Study: assessment process, methods and success criteria, quantitative results, outcome-by-outcome evaluation, continuous-improvement actions, closing-the-loop review history, evidence inventory, graphs, and sign-off. Use Print Full ABET Summary / Save PDF for the formatted report or Copy ABET Narrative for text that can be pasted directly into the ABET document.

Correcting the Assignment Used for Grade Retrieval

If the hub retrieves grades from the wrong Canvas assignment, use Assignment Retrieval Rules on the Grade Entry page. Select the course, enter the exact Canvas assignment column, and connect it to the correct ABET assignment and SLO. Delete the incorrect upload and reupload the gradebook. The saved rule takes priority over automatic matching on every future upload and can later be edited, disabled, or deleted.

Canvas Gradebook Recognition

The one-step importer now recognizes standard Canvas exports that contain blank header rows, a separate Points Possible row, assignment IDs in parentheses, assignment-group summary columns, and course identifiers such as ETDE-1363 inside the filename or Section column. These summary columns are ignored, and the correct point value is taken from the Canvas Points Possible row.

Deleting an Incorrect Canvas Upload

The Grade Entry tab now includes a Manage Canvas Uploads table. Each tracked upload can be deleted individually. Deleting it removes that upload's grade records and any anonymous students used only by that upload, then automatically recalculates the dashboard, SLO outcomes, cycle graphs, and reports.

Multiple Instructors Teaching the Same Course

Each Canvas upload is tagged with the instructor and section. Different instructors can upload to the same course, assignment, and SLO without overwriting one another. Their anonymous students remain distinct, while all student counts and achievement outcomes are combined in the course-level SLO graphs.

Details Beneath Each SLO Cycle Graph

Directly beneath every SLO graph in the cycle comparison section, the hub now lists each assessment cycle's student threshold, number meeting the threshold, number failing, skipped or missing students, total assessed, and success rate.

SLO Threshold, Failure, and Missing-Grade Results

Each SLO report now shows the required student threshold, how many students met it, how many fell below it, how many were skipped or had no usable grade, the number assessed, and the overall threshold success rate. The default threshold is 70% unless a different threshold is already saved for that SLO or in the hub settings.

Combined Course and Section Reporting

Multiple sections of the same course are automatically combined in the default ABET graphs. The section information is still preserved, so the ABET lead can switch the report view to By Section for drill-down details. Uploading another section later automatically recalculates the combined course results.

One-Step Canvas Grade Import

  1. In Canvas, open Grades and export the gradebook CSV.
  2. Open Grade Entry in this hub.
  3. Enter the instructor name once.
  4. Select one or more section CSV files and choose Upload Canvas Grades.
  5. The hub identifies the course, section, assignment, SLO, points possible, and grades.
  6. When the match is reliable, the import finishes automatically.
  7. Only use Advanced Grade Entry when the hub reports that a match needs review.

After a successful upload, the grades, Dashboard, ABET reports, and faculty submission information are all updated. The instructor does not need to select the class, SLO, assessment, or points possible repeatedly.

Sending Faculty Data to the ABET Lead

  1. Complete your Canvas imports, bulk grades, and assessment notes.
  2. Select Faculty Submissions.
  3. Enter your name, academic year, and semester.
  4. Select Export Faculty Submission.
  5. Send the downloaded JSON file to the ABET lead.

The ABET lead imports all instructor files into one master hub. Matching records are updated or skipped according to the selected merge policy, and existing master data is not deleted.

Importing a Class from Canvas

  1. In Canvas, open the course and select Grades.
  2. Select Export and download the Canvas gradebook CSV.
  3. In this hub, open Grade Entry.
  4. Under Import from Canvas Gradebook, select the ABET class and SLO.
  5. Choose the downloaded Canvas CSV.
  6. Review the Smart Canvas Match suggestions for class, assignment, and SLO.
  7. Accept the suggested matches or select different values when needed.
  8. Select the Canvas assignment column you want to assess.
  9. Confirm the ABET assessment name and points possible.
  10. Select Preview Canvas Import.
  11. Review the anonymous IDs, grades, missing scores, and duplicates.
  12. Select Import Canvas Grades.
Canvas student names are read only inside the browser during import. They are not stored in the ABET Hub. The saved records contain anonymous IDs only. Smart Canvas Match uses the CSV filename, Canvas headers, existing course names, and assignments already mapped in the hub. A suggestion is not saved until the instructor confirms the import.

Entering an Entire Class at Once

  1. Select Grade Entry.
  2. In Bulk Class Grade Entry, select the class and SLO.
  3. Enter the assessment name and points possible once.
  4. Enter the number of students and select Generate Anonymous IDs, or select Load Existing Class IDs.
  5. Type all earned grades down the Points Earned column.
  6. Select Save Entire Class Grade List.

You may also paste two columns from Excel or Canvas. Use one line per student, such as A001, 85. When you paste only a column of grades, the hub generates A001, A002, A003, and so on.

Entering a Grade

  1. Select Grade Entry from the left menu.
  2. Under Quick Grade Entry, choose the class.
  3. Enter the anonymous student ID.
  4. Select the SLO being assessed.
  5. Enter the assessment name, such as Lab 2, Final Exam, Presentation, or Rubric Criterion 1.
  6. Enter the points earned.
  7. Enter the points possible.
  8. Select Save Grade.
When you save the grade, the program automatically creates the anonymous student and assessment record when they do not already exist.
