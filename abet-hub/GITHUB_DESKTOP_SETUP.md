# Publish with GitHub Desktop

## First-time setup

1. Install and open **GitHub Desktop**.
2. Sign in to your GitHub account.
3. Select **File → New repository**.
4. Use a repository name such as:
   `osuit-etde-abet-hub`
5. Choose a local folder where GitHub Desktop can create the repository.
6. Select **Create repository**.

## Put the app files into the repository

1. Open the folder GitHub Desktop created.
2. Copy these items from this package into that folder:
   - `index.html`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `icons` folder
   - `README.md`
3. Return to GitHub Desktop.
4. In **Summary**, enter:
   `Initial OSUIT ETDE ABET Unified Hub`
5. Select **Commit to main**.
6. Select **Publish repository**.
7. Uncheck **Keep this code private** if you want to use free GitHub Pages.
8. Select **Publish repository**.

## Turn on GitHub Pages

1. Open the repository on GitHub.com.
2. Select **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Select **Save**.
7. Wait a few minutes and open the published address.

## Updating the app later

1. Replace the old files in the local repository folder with the updated files.
2. Open GitHub Desktop.
3. Review the changed files.
4. Enter a Summary such as:
   `Update ABET Hub`
5. Select **Commit to main**.
6. Select **Push origin**.

GitHub Pages will update automatically.

## Testing checklist

- Open the site on a desktop.
- Open the Diagnostics tab and run the system check.
- Test every navigation tab.
- Test one Canvas CSV using a copy of the data.
- Test print preview for the full ABET report.
- Open the site on a phone and tablet.
- Install it to the device home screen.
